# Changelog

Semantic versioning. / Versionnage sémantique.

## English

### [1.0.0] - 2026-11-11

**Added**
- New name: Multi Manager Roblox, with its own logo and icon.
- Galaxy theme: violet palette, nebula glows and a starfield background.
- New layout: sidebar with every destination, wider window.
- Language chosen at first launch (English or French); the whole app, changelog included, follows it.
- Changelog and website link on the About page.

**Changed**
- Library, Settings, History, Diagnostics, Plugins and About open inside the main window instead of a separate one.
- Rounded buttons, gradient main button, translucent header and footer.
- Updates now come from the Multi Manager Roblox repository.

Based on RoRoRo 1.36.0 by 626 Labs (MIT license).

## Français

### [1.0.0] - 2026-11-11

**Ajouté**
- Nouveau nom : Multi Manager Roblox, avec son propre logo et sa propre icône.
- Thème Galaxy : palette violette, nébuleuses et fond étoilé.
- Nouvelle disposition : barre latérale avec toutes les pages, fenêtre plus large.
- Langue choisie au premier lancement (anglais ou français) ; toute l'application, changelog compris, la suit.
- Changelog et lien vers le site sur la page À propos.

**Modifié**
- Bibliothèque, Paramètres, Historique, Diagnostics, Plugins et À propos s'ouvrent dans la fenêtre principale au lieu d'une fenêtre séparée.
- Boutons arrondis, bouton principal en dégradé, en-tête et pied de page translucides.
- Les mises à jour viennent désormais du dépôt Multi Manager Roblox.

Basé sur RoRoRo 1.36.0 de 626 Labs (licence MIT).
